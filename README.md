# Docs as Code

Практическая работа по настройке среды Docs as Code.

Автор: Никита Абрамов

## Состав проекта

- docs/index.md — главная страница документации.
- mkdocs.yml — настройки сайта, темы и поиска.
- screenshots/site.png — скриншот работающего сайта.

## Запуск

Установить MkDocs:

python -m pip install -r requirements.txt

Запустить сайт:

python -m mkdocs serve
