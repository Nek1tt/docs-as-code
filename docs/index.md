# Документация Никиты Абрамова

Это мой первый сайт документации, созданный с помощью MkDocs.

## О проекте

Проект выполнен в рамках практической работы по настройке среды Docs as Code.
Исходные файлы документации хранятся в GitHub.

## Используемые инструменты

- Git — хранение истории изменений.
- GitHub — размещение репозитория.
- Markdown — написание документации.
- MkDocs — создание сайта из Markdown-файлов.

## Как обновить документацию

1. Изменить текст в папке docs.
2. Проверить результат в браузере.
3. Создать коммит.
4. Отправить изменения на GitHub.
