# Система определения спама

Сервис использует машинное обучение для классификации текстовых
сообщений. Пользователь вводит сообщение и получает результат:
«Спам» или «Обычное сообщение».

Основной пользователь - человек, которому нужно проверить
подозрительное сообщение.

Основные функции:

- ввод текста сообщения;
- определение наличия спама;
- просмотр результата проверки.

## Комплект документации

1. Описание проекта - для пользователей и разработчиков,
   чтобы понимать назначение и основные функции сервиса.
2. Требования - для разработчиков и тестировщиков,
   чтобы определить ожидаемое поведение системы.
3. Архитектура системы - для разработчиков,
   чтобы описать компоненты сервиса и их взаимодействие.
4. Документация ML-модели - для ML-разработчиков,
   чтобы описать данные, обучение и оценку качества классификатора.
5. Руководство пользователя - для пользователей,
   чтобы объяснить порядок проверки сообщения.
