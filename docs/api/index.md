# API

API предоставляет доступ к системе определения спама.

Пользователь передаёт текст сообщения и получает результат:
spam — спам или ham — обычное сообщение.

## Основные операции

- `POST /classifications` — проверить сообщение на спам
  и сохранить результат.
- `GET /classifications/{id}` — получить сохранённый
  результат по идентификатору.
- `GET /labels` — получить список доступных классов.

## Формат запросов и ответов

Тело запроса для проверки сообщения передаётся в формате JSON
и содержит обязательное строковое поле text.

Успешный ответ классификации содержит идентификатор id
и класс сообщения label.

Ответ с ошибкой содержит код code и описание message.
